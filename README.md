# Neotia HR — Module 3 preview

Interactive university HR appraisal foundation prototype using fictional sample records.

Open `index.html` in a browser, or visit the GitHub Pages deployment once published.

## Included

- HR overview and employee directory
- Employee creation and editing
- Workflow assignments
- HOD submission and VP approval or return for correction
- Local audit history and role preview

This is a frontend mockup, not a production HR system. Role switching is illustrative, not authentication. Changes are not synchronized between reviewers. Do not enter real employee information.

## Publishing

GitHub Pages: deploy from `main`, repository root (`/`).
